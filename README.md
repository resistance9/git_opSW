### strong, italic, bold italic, strike 


- main 1 (italic)

  - _text_ or *text* 언더바 혹은 별

- main 2 (strong)
  
  - **text** or __text__ 언더바 2개 혹은 별 2개
  
- main 3 (bold italic)

  - ***text*** or ___text___ 언더바 3개 혹은 별 3개

- main 4 (strike)

  - ~~text~~ 물결 2개
